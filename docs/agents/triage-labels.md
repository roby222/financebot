# Triage labels

Le skill usano cinque ruoli canonici. Applica l'etichetta GitHub corrispondente.

| Ruolo | Etichetta GitHub | Significato |
| --- | --- | --- |
| needs-triage | needs-triage | Il maintainer deve valutare la issue. |
| needs-info | needs-info | Si attendono informazioni da chi ha aperto la issue. |
| ready-for-agent | ready-for-agent | Specifica completa, pronta per un agente autonomo. |
| ready-for-human | ready-for-human | Richiede implementazione da parte di una persona. |
| wontfix | wontfix | Non verrà implementata. |

Per cambiare vocabolario, aggiorna la colonna Etichetta GitHub.
